# XSD BOOST Overlay Icon

The edge overlay handle now uses the supplied HM / Hanzz Project artwork from `app/src/main/res/drawable-nodpi/xsd_boost_overlay.png`. The normal handle displays the complete transparent PNG; hidden mode shows a smaller, lower-opacity version. The edge window width was increased to prevent the artwork from being clipped. Long-press and vertical drag behavior remain unchanged.

Build using the existing GitHub Actions workflow. This source update has not been compiled in this environment.
