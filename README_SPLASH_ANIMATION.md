# XSD BOOST Animated Splash

The app now opens with a Compose-rendered animated splash using `drawable-nodpi/xsd_brand_anime.png`.

Effects included:
- Fade/scale entrance
- Subtle breathing scale on the mascot logo
- Pulsing neon-green radial glow
- Animated loading progress indicator
- Automatic transition to the main app after about 2.8 seconds

The animation is implemented locally in `MainActivity.kt`; it does not require network access or a third-party animation service.
