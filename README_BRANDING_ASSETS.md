# XSD BOOST Anime Branding

Added individual transparent PNG assets:
- `app/src/main/res/drawable-nodpi/xsd_brand_anime.png`: app brand artwork.
- `app/src/main/res/drawable-nodpi/xsd_overlay_mascot.png`: compact overlay mascot artwork.
- `app/src/main/res/drawable-nodpi/xsd_developer_avatar.png`: developer/profile avatar artwork.

Launcher foreground and density-specific launcher icons now use the XSD BOOST anime branding. Settings developer card and developer profile show the mascot avatar.

The generated PNG assets have alpha transparency. Launcher icons intentionally use the app's dark icon background for Android launcher compatibility.
