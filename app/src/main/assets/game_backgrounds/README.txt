XSD BOOST GAME SPACE BACKGROUNDS

Place landscape MP4 files in this folder, for example:
  background_01.mp4
  background_02.mp4

Recommended: H.264, 16:9 or 21:9, 720p or 1080p.
Game Space automatically discovers MP4 files here and loops the selected video.
You can also choose an MP4 from device storage with CHANGE VIDEO.
Video audio is muted by default. Use VIDEO AUDIO to set its volume.
